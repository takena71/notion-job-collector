# Notion 채용공고 수집기

자소설닷컴과 사람인의 공개 채용공고를 직무, 실제 근무지, 학력 조건으로 판정합니다. 신입, 경력, 경력무관, 체험형 인턴, 전환형 인턴을 모두 대상으로 합니다. 분류 옵션과 키워드는 `profile.json`에 있습니다.

## Codex에서 실행

Codex에 아래처럼 요청하면 공개 공고를 확인하고, 로그인된 Notion 앱이나 연결된 Notion 도구로 저장할 수 있습니다. 저장 대상 페이지 링크를 같이 보내면 됩니다. 이 방식에는 Notion API 토큰이나 웹훅이 필요 없습니다.

> 자소설닷컴과 사람인의 채용공고를 소량 검토해서 내 채용공고 수집함에 저장해줘. profile.json의 희망 직무를 적용하고 실제 근무지가 서울·경기이며 학사로 지원 가능한 공고만 저장해줘. 불명확한 건 검토 대상으로 알려줘. 기존 수집함과 지원 현황에서 지원 완료인 회사의 신규 직무는 제외하고, 기존 동일 공고·직무는 본문과 지원 상태를 보존하며 갱신해줘. 접속 실패와 공고 없음은 구분해줘.

## Python에서 미리 보기

Python 3.12 환경에서 처음 한 번 설치합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -v
```

아래 명령은 최대 사이트별 3개 공고를 대상으로 보고서를 생성합니다.

```bash
python fetch_page.py --all --pages 2 --limit 3 --dry-run --output postings-preview.json
```

`collection-report.json`의 `audit`에서 직무별 판정과 근거를 확인할 수 있습니다. `검토 필요`는 실제 근무지, 학력 또는 상세 업무를 확인해야 하는 공고입니다. `failed`는 수집 오류이며 실행 종료 코드가 1입니다. OCR 모델은 이미지 판독 시 필요합니다.

2026-11-23 일반 Chrome에서 두 사이트의 공개 목록, 상세 공고와 2페이지 이동을 확인했습니다. Python에서는 사람인 서울·경기 목록 1·2페이지에서 일반 공고 각 50건을 읽었고, 실제 서울 근무·학력무관 인턴 공고 1건을 콘텐츠 마케팅으로 판정했습니다. 자소설닷컴의 Python 요청은 HTTP 403을 반환했습니다. 자소설닷컴은 일반 공개 화면에서 확인하거나 운영사에 허용된 수집 방법을 문의하세요. 사람인은 승인 후 이용 가능한 [공식 채용정보 API](https://oapi.saramin.co.kr/guide/info)를 제공합니다.

## Notion 속성

표의 순서는 회사, 직무명, 공고 링크, 관심 분야, 마감일, 지원 상태, 출처입니다. 각각 텍스트, 제목, URL, 선택, 날짜, 상태, 텍스트를 사용합니다. 관심 분야 옵션은 `profile.json`의 `interests[].name`과 맞춥니다. 지원 상태에 `검토 전`, `지원 완료`를 사용합니다.

같은 회사·공고·직무는 기존 행의 속성을 갱신합니다. 다른 직무나 모집 차수는 별개 후보로 비교합니다. 지원 완료 회사의 새 직무는 제외합니다. Python 저장 경로는 연결한 수집함의 행을 기준으로 이 규칙을 적용합니다. Codex로 실행할 때는 별도 지원 현황도 함께 읽어서 적용할 수 있습니다.

Python에서 API 쓰기를 사용할 경우 내부 연결을 수집함에 추가하고, `.env.example`을 복사한 `.env`에 토큰과 데이터베이스 ID를 본인이 직접 입력합니다. 다중 데이터 소스에서는 데이터 소스 ID를 지정합니다. 연결은 `python check_connection.py`로 확인합니다.

## GitHub Actions

워크플로는 Actions 탭에서 수동으로 실행하는 미리 보기입니다. 한국시간 매일 오전 9시는 UTC `0 0 * * *`에 해당합니다. 사이트 수집과 Notion 저장·갱신을 검증하고 별도 Notion 인증을 구성한 뒤에 예약을 활성화할 수 있습니다. `.env`, 토큰, 캐시, 수집 결과, 로그는 저장소에서 제외합니다.
